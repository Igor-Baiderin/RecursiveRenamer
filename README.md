# RecursiveRenamer

Бесплатная портативная утилита для Windows для рекурсивного массового переименования файлов и папок.

RecursiveRenamer позволяет найти заданный фрагмент текста в именах файлов и каталогов и заменить его другим текстом. Если поле замены оставить пустым, найденный фрагмент будет удалён.

## Возможности

- массовое переименование файлов;
- массовое переименование папок;
- рекурсивная обработка вложенных каталогов;
- поиск и замена текста в именах;
- удаление заданного фрагмента из имени;
- предварительный просмотр изменений без переименования;
- отдельное включение обработки файлов и папок;
- журнал выполненных операций и ошибок;
- поддержка Unicode, включая русские имена файлов и папок;
- защита от перезаписи существующих файлов;
- не требует установки.

## Использование

1. Выберите папку для обработки.
2. В поле **«Найти в имени»** укажите текст, который необходимо найти.
3. В поле **«Заменить на»** укажите новый текст.
4. Чтобы просто удалить найденный фрагмент из имени, оставьте поле **«Заменить на»** пустым.
5. Выберите, что обрабатывать: файлы, папки и вложенные каталоги.
6. Нажмите **«Проверить»**, чтобы предварительно увидеть изменения.
7. Если результат правильный, нажмите **«Выполнить замену»**.

Рекомендуется всегда использовать предварительную проверку перед выполнением массового переименования.

## Системные требования

- Windows 10 / Windows 11
- установка не требуется

## Сборка

Программа написана на C с использованием Windows API.

Проект подготовлен для Code::Blocks и MinGW GCC.

Используемые системные библиотеки:

- shell32
- comctl32
- ole32

Для GUI-сборки используется параметр линковщика:

    -mwindows
